# 质量评测可靠性改进

2026-09-08。本轮完善质量评测的评分、错误定位和文件复用流程，不改变 M07 真实业务验收状态。

## 修复的问题

- 原评分通过默认 28 位 Decimal 上下文计算差值，`1.00000000000000000000000000001` 与 `0` 在容差 `1` 下会误判通过；`1e9999999` 会触发溢出异常。现在零容差直接精确比较，非零容差使用按输入有效位数确定的精度及向上舍入的非负差值，避免跨越容差边界；指数跨度不决定内存分配的精度。
- 无序精确比较改用保留数据类型与重复数量的计数集合。数值先解析一次，不再逐对重复解析；带容差且不完全相同的结果仍使用完整匹配，保留重叠容差下的正确性。最坏情况下的非零容差匹配仍为二次规模候选图，本轮没有取消每题 1000 行限制。
- 评分新增 `scoring_version: 2` 和逐题 `difference`。区分截断、列名称/顺序、行数、行宽、非法数值、顺序/结果差异、重复行、动作不符、已报告错误及关键错误。只保存诊断码、行列位置和行数，不把结果单元格写入未加密摘要。

## 管理员使用

打开 `/quality` 的“质量评测”。展开逐题错误分析，默认只看未通过题目，每页最多 20 题；取消勾选可查看通过题目，切换筛选自动回到第一页。旧运行没有具体诊断时提示查阅导出证据，历史分数不会被静默重算。

题集和运行均可导入原始 JSON 或本页导出的 `definition` 包装文件，也支持 UTF-8 BOM。格式错误、文件类型选错、超过 2 MB 均提供具体中文提示；服务端校验和原有摘要检查保持生效。导入成功后显示反馈，并切换到相应题集与开发/盲测集合。失败时保留原选择。

**重新导入题集会创建新的题集记录；运行证据继续关联其原始题集 ID 和摘要。** 此功能用于复用文件，不是自动迁移全部题集/运行关系。导出题集仍保留 `id`、`digest`、`definition`，兼容现有 `scripts/evaluate_questions.py`。

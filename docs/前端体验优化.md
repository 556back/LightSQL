# 前端体验优化（2026-09-07）

保留现有数据目录和业务主题的模型，调整用户看到的名称、操作顺序和页面布局。

## 使用流程

1. **数据库连接**：维护数据库连接信息。
2. **数据表目录**（原元数据目录）：选择允许使用的表，默认保存后同步字段与关联；也可取消自动同步。保存成功但同步启动失败时，明确提示选表已保存，并指引使用“更新表结构”重试。
3. **业务主题**：将相关表整理成一个分析范围。新主题默认从选表开始，再按需要添加维度和指标；关联、统计条件、名称与别名放在高级配置中。
4. **智能问数**：从已发布主题卡片或业务口径页直接进入问数，并自动带入主题。

数据表目录前往业务主题时保留数据库选择；主题缺少数据表时，返回目录也会带上绑定的数据库。查询参数使用 `source`，例如 `/catalog?source=<数据源 ID>`。

## 交互与布局

- 主题增加状态筛选、搜索与清除筛选；显示草稿、停用及需要重新检查时的下一步提示。
- 配置自动生成内部标识，默认折叠技术标识；单表时自动选择所属表，切换所属表会清空旧字段。主键继续从目录读取，业务名称可从表注释带入。
- 导航分为探索与分析、数据准备、系统管理，主题详情页保持导航高亮；普通成员的导航不显示管理入口。
- 统一背景、文字、边框和主色，调整页面宽度、卡片、弹窗、按钮及标题；显示主题菜单改为中文。
- 窄屏下目录统计保持一行，表列表限制高度，内容区域允许收缩，长字段表格在区域内滚动。弹窗限制在视口高度内。

- `npm --prefix frontend run build`：TypeScript 检查与生产构建。
- 修改的 21 个应用文件通过 Biome 检查。
- `node scripts/tests/frontend_ux.cjs`：使用本地服务提供构建产物，在浏览器中拦截 API 并使用固定样例数据。覆盖创建、内部标识、表与字段切换、主题与数据库跳转、搜索与筛选、保存后同步、部分失败和冲突、普通成员入口、390px 窄屏及深色主题。
- 回归脚本不写实际数据库，也不调用模型。截图与结果写入 `.local/ux-review/`。可通过 `LIGHTSQL_UI_URL` 指定本地服务，默认 `http://127.0.0.1:8000`。

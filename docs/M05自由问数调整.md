## 使用

打开 `http://127.0.0.1:8000/ask`，选择数据范围并新建会话。默认“自动：指标口径 + 自由探索”，可切换“自由探索表字段”或“仅标准指标口径”。默认校验通过后自动查询，也可取消勾选并手动执行。

示例：

- 我想看看订单明细，按日期倒序列出最近五笔，包含订单号、渠道、订单金额和退款金额。
- 改成按渠道统计订单数和退款金额，画柱状图，并给我一些分析建议。
- 按日期统计退款金额，并计算上一个有订单日期的退款金额，画折线图。
- 本月净销售额按客户区域分组（优先沿用已发布的净销售额口径）。

数据主题作为一个数据集/业务范围，绑定授权目录中的表、字段及关联，可以没有任何指标。已有指标是可信业务口径的可选输入，不再是问数唯一入口。当前仍需选择范围并发布，以确定使用哪些表，暂不支持跨数据源查询。

## 实现与权限

- `QueryPlan` 保留标准指标路径；`SqlPlan` 支持明细、自定义聚合、关联、排序、CASE、CTE、子查询及窗口比较。模型只见逻辑表名与可用字段，物理 schema/table 由本地绑定。
- 移除问句词语白名单和长数字一刀切拦截。一般自然语言、用户明确给出的筛选值正常进入模型上下文；已登记实体本地替换为引用。此行为不宣称自动识别所有敏感信息。
- 管理员可探索主题数据模型的非敏感字段。成员必须在“查询授权 → 自由探索表字段”逐列授权，指标汇总权限不会自动变成明细权限。每张授权表必须配置行范围或显式允许全部行。
- 模型 SQL 使用 PostgreSQL 规范语法，本地 SQLGlot 正向 AST 白名单和字段解析验证后转换为源库方言。拒绝多语句、写入、SELECT INTO、锁、系统目录、表函数、自定义函数、递归查询及未授权字段。
- 每次物理表引用均替换为独立的字段投影和行范围过滤，包括 CTE、子查询及 JOIN 两端。查询期间、结果领取时继续检查发布版本和授权。字符串使用驱动参数绑定，执行复用 M04 Worker 的只读事务、限时、取消、结果字节/行数限制和清理确认。
- SQL 追问先将上轮字符串条件转换为本轮引用；SQL 在本地恢复引用后执行。标准指标仍保留固定业务过滤，自由 SQL 不默认套用指标口径，页面显示具体 SQL。
- 模型仅建议图表类型，实际图表数据来自查询结果。柱状/折线可切换横轴和数值列；最多绘制前 40 行，不再聚合同名分类，NULL 不作为零，精确值在表格及悬停提示中保留。
- 请求分析或点击分析按钮时，先用 Decimal 计算返回行的最小值、最大值和均值，再由配置模型解释。长均值按约数标注，事实引用必须存在；模型文字不允许夹带未经计算的阿拉伯数字。分析明确受查询条件、截断和返回行范围限制，不等同全库统计或因果分析。模型解释仍需要业务判断。
- 现有模型配置、密钥及 M03/M04 数据保留。无新增关系表或数据库迁移，新增字段采用现有 JSON 结构兼容扩展。

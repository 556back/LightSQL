## 已实现

| 能力 | 行为与边界 |
|---|---|
| 长期反馈 | 保存反馈时，在同一事务中复制问题、计划、模型版本、反馈及来源版本到独立加密记录。会话 24 小时到期后仍可审核；不复制结果表。自首次提交保留 90 天，查询 Worker 心跳与管理员读取时清理到期内容；审计保留无正文的动作记录 |
| 审核与回归 | 待审核、已确认、不采纳、已解决；要求审核说明。已解决必须关联同一主题的现存回归题，使用 revision 防止覆盖新反馈。用户修改后重新待审核，保留审核历史。审核不自动发布生产语义或进入模型检索 |
| 题集 | 不可变版本及 SHA-256 摘要；记录主题、语义版本、数据快照说明、时间、时区、角色、参考 SQL/计划、结果断言、题目分组、开发/盲测集合和合成/业务审核来源。限制同分组横跨两集合，但不能自动识别人工错误标记的近重复问题 |
| 结果评分 | 每次运行必须恰好覆盖所选集合全部题目；漏题、重复题和摘要不匹配直接拒绝。金额用 Decimal，区分 NULL、布尔和数值；检查列 ID 与顺序、行数、重复行、截断及可配置容差。无排序要求可忽略行序，带容差时使用完整行匹配 |
| 质量统计 | 总正确题数、可回答题端到端正确率、覆盖率、已回答精度、错误回答数、关键错误、错误分类、P50/P95、已提供的用量及费用。误拒答算失败；未知费用或未测用量不会伪装成零；关键错误即使数值正确也不算通过 |
| 对照管理 | 同一题集内分别查看开发与盲测记录；保留模型、配置说明、A/B/C/D 上下文方案及协议回放/真实模型/人工证据类型。导入者对这些外部标签负责，页面不认证来源、不自动选模型或宣布上线达标 |
| 运行脚本 | `scripts/evaluate_questions.py` 从导出题集经正常鉴权问答、执行和结果 API 收集观察值，逐题独立会话，支持历史追问；固定当前模型配置，不切换线上模型。当前脚本实现 C 路径，A/B/D 可导入经过独立审核的外部实验观察值 |
| 运行监控 | 15 秒刷新；两类 Worker 每 10 秒向元数据库报心跳，超过 35 秒告警；队列等待、未确认清理任务、近 24 小时查询状态/各源平均耗时、规划 Token、反馈数量、应用磁盘、最近成功备份和该备份恢复验证时间 |
| 备份恢复 | `scripts/metadata_backup.py` 使用 PostgreSQL 一致性导出快照备份 public 元数据 schema，记录表行数、文件大小及摘要；恢复只接受自动生成的新数据库，不覆盖既有库。核对表集合、行数及所有非空加密字段能否解密 |
| 启动顺序 | Compose 增加一次性 prestart，先执行 Alembic 迁移与初始化，再启动 API 和 Worker；显式关闭公开注册 |

## 题集与评测复现

初始文件为 [五题合成冒烟题集](examples/M07合成冒烟题集.json)。导入前将 `topic_id`、`semantic_version` 改成实际的“M05 合成销售问答”主题和发布版本，核对合成表仍是指定五行；不要把此文件标记为 `business_reviewed`。

管理员在“质量评测”上传 JSON 后，点击“导出题集”。导出文件包含服务器分配的 `id`、`digest` 和 `definition`，供运行器使用：

```powershell
# LIGHTSQL_EVAL_TOKEN 在当前进程环境中提供，不写进命令、文件或版本库。
.venv/Scripts/python.exe scripts/evaluate_questions.py .local/gold-export.json --url http://127.0.0.1:8000 --output .local/run-new.json --split dev --evidence live_model
```

该命令调用当前配置的真实模型并正常执行源库只读查询；先核对题目和外发许可。默认不计入未知模型 Token 和费用。使用回放 API `8005` 时必须指定 `--evidence protocol_replay`。角色字段当前运行器接受 `admin`（需管理员身份）或当前账户邮箱；网关版本读取要求管理员，因此成员角色自动评测暂不由该脚本执行，成员权限继续由既有回归与人工验收覆盖。

运行器只收集结果，不读取参考答案作答。问答错误仍生成观察记录，不会漏题抬高分数；模型/语义配置中途变化则中止，部分文件不能导入完整运行。快照名称和角色需维护者事前核对，不能以文件声明代替业务源库冻结。错误分类、关键错误、费用和实际服务商版本须复核后导入。A/B/D 对照不能简单改标签冒充实际实验；当前没有自动构造或外发完整敏感上下文的入口。

当前 JSON 契约见 OpenAPI 的 `DatasetInput`、`GoldCase`、`RunInput` 和 `Observation`。单个加密记录上限 2 MB；题集最多 500 题，每题结果最多 1000 行。数值列按 `numeric_columns` 声明，非数值列精确匹配；日期/时区格式需评测前统一。题集和运行列表每页最多 100 项，API 通过 `offset` 翻页；页面题集与运行选择当前显示最新 100 项。

独立浏览器验收：

```powershell
# 第一个终端：独立元数据库及回放模型，不覆盖主环境。
.venv/Scripts/python.exe scripts/module5_demo.py fixture-api
# 第二个终端：端到端回放与页面操作。
node scripts/module7_browser.cjs
```

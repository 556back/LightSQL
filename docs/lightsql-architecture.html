LightSQL

将自然语言问题转化为受控查询，连接 PostgreSQL、MySQL 和 Oracle。

查询规划与结果分析使用不同的模型输入

查询规划使用用户问题与受控上下文。结果分析向模型发送安全处理后的问题，以及本地计算的数值事实。模型网关仅访问白名单中的 HTTPS 地址；业务数据库查询由执行进程完成。

本图范围

依据当前代码与 Docker Compose 拓扑绘制。各 API 模块归入同一进程，查询执行与目录采集分别运行。图中省略连接探测、启动迁移、邮件、可选的 Sentry 及开发工具；不代表实际部署状态。

代码依据与说明

compose.yml 定义代理、后端、元数据库及两类后台进程。backend/app/main.py 提供前端页面与 API。backend/app/api/main.py 注册各业务模块。backend/app/modules/assistant/{service,gateway,analysis}.py 实现查询规划、模型调用与基于事实的分析。backend/app/modules/query/{service,worker,executor}.py 实现任务提交、共享调度与隔离执行。backend/app/modules/catalog/{worker,introspection}.py 实现元数据采集。当前业务数据库范围为 PostgreSQL、MySQL 和 Oracle，见 README.md；暂缓兼容的数据库未列入本图。应用数据库除元数据外也保存查询结果快照，业务源数据库仍为权威数据来源。

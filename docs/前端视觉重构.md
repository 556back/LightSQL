# 前端视觉与交互重构（2026-09-08）

视觉方向是“数据光谱工作台”：深蓝导航、雾白内容区、青绿色操作按钮，以及仅用于入口的抽象数据轨迹。保留原有数据库连接、选表、主题发布、问数和管理流程。

## 主要变更

- 登录、主题、问数和数据库连接入口重新组织视觉层级；管理页面继承统一的颜色、字体、按钮、卡片和深色模式。
- 新增共享 `PageHeader`、`DataSpectrum`、`SearchInput`、`ValidatedForm`。语义字段补齐标签关联，域表单把已有 HTML 约束转换成中文行内错误、无障碍错误关联和首项聚焦。RHF 表单继续使用已有 schema 校验。
- 主题每次显示 12 项，显式加载更多；数据库连接每页 10 项，筛选后回到第一页，数据减少时限制有效页码。搜索有清除按钮，清除后焦点回到输入框。
- 删除会话增加确认，默认聚焦取消，失败保留弹窗并允许重试；关闭弹窗恢复触发按钮焦点。
- 导航增加跳过链接、当前页标记和中文无障碍名称；快捷键避开输入框及 IME；生产构建隐藏开发调试工具。
- 统一可见滚动条、焦点和减少动态效果规则。文本框保持足够高度并内部滚动，避免拖拽破坏布局。错误页改为中文，并使用正确的导航链接语义。
- `DESIGN.md` 和 `UX-CONTRACT.md` 记录视觉来源、运行时 token 所有权和跨页面操作约定。

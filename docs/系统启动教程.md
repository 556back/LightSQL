# LightSQL 系统启动教程

本地开发和单机体验请直接阅读 [本地开发启动教程](本地开发启动教程.md)。推荐使用仓库提供的一键 PowerShell 脚本：它会统一管理配置、数据库、API、前端和三个后台 Worker。

```powershell
Set-Location D:\Projects\LightSQL
.\scripts\start-local.ps1
```

启动后访问 http://localhost:18000。管理员、数据库和加密密钥集中保存在 `.local\startup.env`；文件只保存在本机并已被 Git 忽略。

常用命令：

```powershell
.\scripts\start-local.ps1 -Action status
.\scripts\start-local.ps1 -Action logs
.\scripts\start-local.ps1 -Action stop
.\scripts\start-local.ps1 -Action reset-admin
```

忘记管理员密码时，修改 `.local\startup.env` 的 `FIRST_SUPERUSER_PASSWORD`，再运行 `-Action reset-admin`。忘记数据库密码且没有旧配置备份时，确认本地数据可以删除后运行 `-ResetData`，脚本会只重置当前项目的元数据库卷。

生产部署不应直接使用此开发脚本。生产环境应使用独立密钥管理、持久化备份、HTTPS 反向代理和部署专用 Compose 配置。

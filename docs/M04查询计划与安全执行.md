## 2. 实现范围

| 功能 | 实际行为 |
|---|---|
| 计划 | 最多 10 指标、5 分组维度、20 附加过滤；只接收稳定语义标识，拒绝 SQL、源连接、角色、策略和版本等未知输入字段 |
| 服务端绑定 | 通过 `resolve_published` 绑定当前可用发布版本、授权目录、源配置和用户；草稿不参与执行 |
| 编译 | SQLGlot 28.10.1 构造允许清单内的 AST；所有物理标识引用并转义；值使用 DB-API 参数；仅固定内置聚合、受控日期格式和比率函数 |
| 指标 | 同一基础模型、相同固定过滤和时间口径的指标可共同查询；支持 sum/count/count_distinct/avg/min/max/ratio；分母为零返回 NULL |
| 关联 | 沿已发布语义层的唯一有向路径连接；复合键完整配对；行级授权先作用于基础关系子查询，再参与外连接与聚合 |
| 日期 | 业务日期支持原值、日、月、年分组；区间左闭右开；时间戳过滤要求显式偏移并转换到源字段的 UTC/主题本地语义；时间戳日/月分组明确拒绝 |
| 授权 | 主题成员资格之外，管理员显式配置成员指标、维度和每个基础模型的组织/租户编码；或显式允许全部行。缺少授权默认拒绝；管理员可查全部授权数据 |
| 授权失效 | 授权绑定发布版本和行范围字段结构；重发语义、字段类型/可空性变化需要重新保存确认；撤销成员或查询权限后旧结果不可继续读取 |
| 执行队列 | PostgreSQL 持久任务；请求 UUID 幂等；重复标识不能替换计划或权限；每用户最多 3 个占用任务、每源 20、总队列 100；全局同时执行 1 个已确认的查询 |
| 运行复核 | 执行前、执行期间、结果落库前及每次读取结果时复核用户、版本、目录和策略；查询期间发生变化时停止并丢弃结果 |
| 取消与异常 | 排队任务立即取消；运行任务进入 cancelling，等待真实源库取消与回滚确认；连接异常、进程退出、租约超期不能直接认定已停止 |
| 不确定清理 | 状态 `cleanup_pending` 持续占用源额度，禁止该源新查询，不自动重试；执行 SQL 带 `lightsql_job:<UUID>` 标记供 DBA 定位；管理员核实源库操作结束后填写依据、解除占用，留审计 |
| 限额 | 每查询 1–30 秒（默认 15）；最多 1000 行（默认 100），源 SQL 多读取 1 行判断截断；结果行载荷最多 2 MB、单个文本单元格最多 16 KB |
| 结果 | Decimal、大整数为十进制文本，不经过 JavaScript 浮点数；日期为 ISO 日期、时间戳附源语义时区、布尔和 NULL 保留；拒绝二进制/大对象/复合值 |
| 留存 | 结果与原始计划 24 小时，到期不可访问，Worker 清除内容；任务摘要与必要审计 90 天；不缓存复用历史结果 |
| 前端 | 指标与过滤表单、校验预览、执行状态、取消、结果表格、截断提示、最近 50 条查询、成员查询授权、管理员审计和清理确认 |

普通成员接口不返回物理 SQL、数据库凭证或行授权配置。结果接口仅向任务创建人开放，管理员审计不等于查看他人结果。错误和拒绝记录不保存过滤参数、凭证或源库异常原文；查询计划为短期内部数据，随结果到期清除。

2 MB 是已读取结果行序列化载荷的上限，不是数据库扫描量、网络包或进程峰值内存的硬上限。源 SQL 行数限制不能替代执行时间限制。外层守护进程在时限后继续留出清理窗口；无法确认清理时明确暂停数据源。

## 3. 五库能力与实测

沿用 M01/M02 的五个隔离容器和专用只读账号。向原来空的 `m02_customers/m02_orders` 添加 3 个客户、4 笔合成订单：跨租户复用客户号、1 笔金额为 NULL，合计 3500.60。保留所有 M03 表和发布记录。脚本遇到不同规模的已有数据拒绝覆盖。

| 数据库 | 绑定、复合关联、精确金额 | 行范围、截断、零分母 | 超时 / 主动取消（实测约） | 产品执行入口 |
|---|---|---|---|---|
| PostgreSQL 18 | 通过，3500.60 | 通过，租户 1 为 2000.30 | 1031 / 1104 ms；取消与回滚确认 | 开放 |
| MySQL 8.4 | 通过，3500.60；PyMySQL 转义参数 | 通过 | 1013 / 1106 ms；同账号 KILL QUERY、回滚确认 | 开放 |
| Oracle 26ai Free | 通过，3500.60；NUMBER 用 Decimal | 通过 | 1052 / 1025 ms；Connection.cancel、回滚确认 | 开放 |
| 金仓 V9 PG 模式 | 通过，3500.60 | 通过 | 1018 / 1107 ms；PG 取消协议、回滚确认 | 开放，仅此兼容模式 |
| 达梦 DM8 / dmPython 2.5.38 | 通过；位置参数；固定 4 行合成数据直接验证 | 参数化行规则可编译；未宣称受限执行通过 | 驱动无公开 cancel / 语句限时接口，未验证可靠替代方案 | 关闭；可编译预览 |

四库均用实际长查询执行一次约 1 秒超时和一次主动取消，确认返回后可完成回滚。没有扩大只读账号权限来实现取消。达梦 `connection_timeout` 不作为查询已停止的证明；M01 连接测试和 M02 元数据同步维持原行为。达梦人工复合键关联仍依赖已确认主键，外键字典可见性限制不变。

日期月份分组在 PostgreSQL 的实际业务主题上通过 HTTP/Worker 验证；其他四库的日期格式编译有回归用例，尚未分别验证完整日期/时区类型矩阵。新目标版本、TLS、网络故障、源库权限变更与复杂类型仍需按部署环境验证。

## 6. 边界与后续

M04 不调用模型 API，不实现自然语言问数、跨模型事实表合并、跨源 JOIN、任意表达式、时间戳日/月分组、查询成本估算、结果缓存或导出。Oracle/达梦空字符串过滤明确拒绝，避免与 NULL 混淆。只读账号和授权视图仍由 DBA 配置，应用层授权不能替代源库最小权限。

当前 Worker 用持久租约和保守清理状态控制失败，不提供自动源会话清理器；待清理任务需要 DBA 核实后管理员记录依据。任务 UUID SQL 标记用于定位查询，不是可自动取消的厂商 session handle。需要高并发或自动故障恢复时，应继续扩展原生会话标识、清理器和数据源级额度，不应直接增加 Worker 数量绕过限额。

M04 已于 2026-09-07 通过用户验收，进入 M05：语义检索、实体解析、结构化计划生成、歧义澄清、多轮上下文与模型网关。按用户要求暂缓达梦和人大金仓兼容，国产库历史能力不构成下一阶段验收要求。

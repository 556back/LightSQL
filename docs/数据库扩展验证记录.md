## 3. 复现（项目根目录，PowerShell）

先按 [模块建设与验收](模块建设与验收.md) 安装依赖、生成 `.local/demo.env` 并完成 PostgreSQL/MySQL 的 `seed`。不要删除已有 `.local/demo.json` 后复用旧数据卷，否则生成的新密码和旧实例密码将不一致。

```powershell
# Oracle 为默认演示服务，可单独启动。
docker compose --env-file .local/demo.env -f compose.demo.yml up -d oracle
docker logs --tail 30 lightsql-module-demo-oracle-1
# 等待 DATABASE IS READY TO USE 后执行；首次初始化需数分钟。
.venv/Scripts/python.exe scripts/extended_databases.py oracle

# 达梦官方镜像归档。
curl.exe -fL --retry 2 -o .local/dm8_20241022_x86_rh6_64_single.tar https://download.dameng.com/eco/dm8/dm8_20241022_x86_rh6_64_single.tar
Get-FileHash .local/dm8_20241022_x86_rh6_64_single.tar -Algorithm SHA256
# 核对上文摘要后导入；Compose 不会从其他 registry 自动获取同名镜像。
docker load -i .local/dm8_20241022_x86_rh6_64_single.tar
docker compose --env-file .local/demo.env -f compose.demo.yml --profile extended up -d dameng kingbase
docker logs --tail 30 lightsql-module-demo-dameng-1
docker logs --tail 30 lightsql-module-demo-kingbase-1
# 分别等待 SYSTEM IS READY 和 server started 后执行。
.venv/Scripts/python.exe scripts/extended_databases.py dameng
.venv/Scripts/python.exe scripts/extended_databases.py kingbase

# 五库全部初始化成功后执行模块回归。
.venv/Scripts/python.exe scripts/module1_demo.py test
```

重新生成客户端、构建前端和启动 API 的命令见主验收文档。国产库位于 Compose `extended` profile；默认启动命令不依赖本机已导入达梦镜像。停止本任务全部演示数据库并保留数据卷：

```powershell
docker compose --env-file .local/demo.env -f compose.demo.yml --profile extended stop
```

## 4. 适配与代码复查

- 后端数据源类型扩展为五种，继续共用管理员鉴权、凭证加密、主机白名单、revision 并发保护、审计和错误脱敏。存储列为字符串，增加类型无需修改数据库结构。
- Oracle 使用显式分支，避免新类型落入 Oracle 驱动。Free lite 不含 USERS 表空间，演示脚本根据实际 SYSTEM 数据文件目录创建独立 `LIGHTSQL_DEMO` 表空间，设置 100 MB 上限。
- 达梦通过驱动的 `schema` 参数设置默认模式，使用原生只读 access mode、登录与连接超时；不拼接用户提供的 `SET SCHEMA`。驱动 C 扩展没有类型存根，对单个 import 作明确类型工具注释，实际安装和连接已验证。
- 金仓当前只支持已经实测的 PG 模式。连接显式设置 `client_encoding=utf8`；演示数据库创建为 UTF-8，避免镜像默认 SQL_ASCII 导致字符返回 bytes。
- 默认仍请求 TLS 证书校验。Oracle/MySQL/PG/金仓用各自严格模式；本地无受信任证书时必须失败。达梦证书校验未实现，请求 `verify-full` 时明确拒绝，不自动降为明文。当前达梦演示仅使用回环地址的明文连接。
- 表单新增达梦/金仓，提供正确默认端口、达梦 Schema 标签、金仓模式提示与达梦 TLS 能力说明。详情和筛选使用相同类型定义；OpenAPI 客户端已重新生成。
